# Codex Rules

- Read all project documentation before coding.
- The documentation is authoritative.
- Work on one milestone only.
- Do not silently change the chosen stack.
- Do not invent official GuildRun data.
- Use placeholder data and assets with explicit labels.
- Do not scrape third-party content.
- Never skip server authorization.
- Never mark a milestone complete with failing checks.
- Keep a concise implementation log in the final response.
