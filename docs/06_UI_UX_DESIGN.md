# UI and UX Design

## Mobile-first

Primary mobile navigation:

- Home
- Search
- Create
- Patches
- Profile

The Create action is centered and visually emphasized.

## Desktop header

- Brand
- Global search
- Compositions
- Builder
- Characters
- Items
- Patches
- Tier List
- Meta
- Login or user menu

## Homepage

- Intro and global search
- Latest patch
- Best compositions
- Trending compositions
- Recently updated compositions
- Recommended creators
- Tier-list preview
- Builder call to action

## Composition card

Display:

- title;
- tier;
- patch;
- verification/status;
- unit portraits and rough positions;
- brief explanation;
- strengths;
- author;
- last updated;
- views, saves and votes.

## Accessibility

- visible focus;
- keyboard navigation;
- semantic dialogs;
- accessible tooltips;
- screen-reader board announcements;
- non-drag alternatives;
- sufficient contrast;
- form labels and readable errors.
