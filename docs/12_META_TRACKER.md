# Meta Tracker and Tier Lists

## Internal meta

Use only activity from Guild Tactics:

- most viewed compositions;
- most favorited;
- most positively rated;
- rising and falling compositions;
- most used characters, items and relics in published guides;
- change versus previous patch.

Always label this as:

- Community trend
- Guild Tactics usage
- Published guide data

Never call it official in-game usage without an official data source.

## Tier lists

Support tier lists for:

- compositions;
- characters;
- items;
- relics;
- game modes;
- patches.

Tiers:

- S
