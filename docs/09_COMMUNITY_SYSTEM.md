# Community System

## Profiles

Public profile:

- avatar;
- username;
- bio;
- badges;
- published compositions;
- followers and following;
- total views and likes;
- optional social links.

## Roles

- GUEST
- USER
- CREATOR
- VERIFIED_CREATOR
- MODERATOR
- ADMIN

## Interactions

- Favorite
- Helpful / Not helpful
- Works / Does not work
- Comments and replies
- Follow creators
- Report content
- Share composition

## Reports

Reasons:

- spam;
- incorrect information;
- outdated;
- duplicate;
- abusive behavior;
- copyright concern;
- other.

## Notifications

- new patch;
- composition requires update;
- comment or reply;
- vote or favorite;
- verification result;
- moderation action;
- new follower.
