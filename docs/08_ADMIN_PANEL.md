## Rapid item entry

Optimized workflow for repeated entry:

- upload image;
- name and internal key;
- category and rarity;
- structured stats;
- effect;
- patch;
- source;
- verification state;
- image state;
- save and add next;
- duplicate;
- tooltip preview;
- duplicate detection;
- CSV and JSON import.

## Moderation

Moderators can:

- review reports;
- hide or restore content;
- soft-delete comments;
- flag guides as outdated;
- request creator updates.

Admins can manage all data and permissions.
