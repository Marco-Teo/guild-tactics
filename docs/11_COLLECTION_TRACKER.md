# Collection Tracker

Registered users can record:

- owned characters;
- available items;
- available relics;
- unlocked specializations.

## Outputs

- compositions immediately playable;
- compositions nearly playable;
- missing elements;
- characters that unlock the most new compositions;
- priority items and relics;
- personalized composition recommendations.

## Matching

A composition receives:

- completion percentage;
- missing core elements;
- missing optional elements;
- valid substitutions;
- patch compatibility.

Collection data is private by default.
